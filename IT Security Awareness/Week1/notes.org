* IT Security Awareness Training Video

** Why IT Security Training Matters?

- Helps to combat problems when they arise, and helps to remain in compliance with company policiese and even laws.
- There are monetary and legal risks if not in compliance.

** Main Reasons for Breaches in Security

- Human error and/or carelessness
- Social Engineering

** Actions to Mitigate Security Breaches

- Update all anti-virus countermeasures (software like norton).
- Don't install unapproved software.
- Keep OS current with updates.
- Log-off when computer is idle - use password protection.
- Keep physical docs secure and locked away.
- Clear screen and clear desk policy.
- Don't write passwords down - ever.
- Never open unknown emails.
