Calculating Percentage Program

Problem Statement

Design a program that will receive a fraction in the form of a numerator and a denominator, convert that fraction to a percentage and display the result. Your program is to use a function to calculate the percentage. Use another function to round the percentage to the nearest tenth. Create other functions as you see the need for them.

View the HTML Form at the bottom of this page. The JavaScript in located in demo-calc-percentage.js
