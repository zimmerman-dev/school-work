Problem Statement

In this lab you will be writing a JavaScript program that, each time the submit button on the form is clicked, it will accept a string from a text box on a form, and save the string into an array. The array will increase by one string each time the submit button is clicked, thus gradually increasing the number of ‘slots’ in the array. In addition to acquiring another string, the entire contents of the array as it exists at that point in time must be displayed on the Web page. Note: There is just one function involved with this lab, namely the main function named: lab06().

Lab Steps

There is no script block within the HTML file source code because the JavaScript program for this lab will be run by clicking the submit button on the form.

  1. In the HTML file, create a form with one input text box field and a submit button.
  2. Give the form an id attribute, or, give the text box field itself an id attribute (which one depends upon how you later wish to generate a reference to the string keyed into the text box).
  3. Add an HTML <ol> element below your form, to display your output on the web page.
  4. Give the <ol> element an id attribute, with a value of something like outputList.
  5. Give an onsubmit event attribute to the form, an attribute which calls the lab06() function.
  6. TEST: Check to make sure a click of the submit button does call the function lab06(). Does the function have a return a value of false?

  7. Create and initialize an empty global array variable to hold the strings that will be entered by the viewer. Why does this need to be a global variable?

  9. In the lab06() function, create a local variable to hold a reference to the HTML display element, in this instance it is the <ol> tag.
  10. Get a reference to the <ol> and assign it to the local variable.
