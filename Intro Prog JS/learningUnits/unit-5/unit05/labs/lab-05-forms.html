Lab Steps

The HTML File

  1. Add a form to this HTML document after the Add your form below this line comment.
  2. Add an id attribute on your form element.
  3. The form should have four input text fields:
    • A field for an address
    • A field for a city
    • A field for a State
    • A field for a zip code
  4. The form should have a submit button that reads “display address”.
  5. The opening form tag should have an onsubmit= event attribute that calls a function named displayFormattedAddress(). There must be a return returning a Boolean value of false.
  6. Just below the form, add a <br/> and a <div> element. Give the <div> an id attribute so the JavaScript function can access it.

The JavaScript File

  1. Create a function in the JavaScript file named displayFormattedAddress().
  2. TEST Make sure the new function works by using an alert() method.
  3. Your function will need to get the values of all the input fields on the form and store them into local variables.
  4. The function will create a formatted address output something like this:
    123 Some St.
    Madison, WI 53704
  5. Output the formatted address to the output <div> element by using the innerHTML property.
