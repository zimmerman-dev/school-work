Lab Steps

  1. Create the “skeleton” of a new function above the main function called displayCity(). Don’t forget to set up a comment just above it, with a one sentence first draft telling the purpose of this new function (which is to display a city).
  2. TEST:Place an alert() inside the displayCity() function and call it from the main function to make sure it is working.
  3. In the function lab03(), prompt the user for a city name. Use a local variable to hold the city keyed in by the user.
  4. In the new displayCity() function, add a parameter within the parentheses. Name it something like cityReceived. This creates a special type of local variable that is available only within the new displayCity() function.
  5. Then back in the main function lab03(), modify the call to the displayCity() function. Place the name of the local variable holding the city name from the prompt() inside the parentheses as an argument
  6. TEST: Validate that the value of the variable holding the entered city name has been passed into the displayCity() function. Do this by placing the cityReceived parameter into an alert() method inside the displayCity() function. It should successfully alert out the entered city name.
  7. In the displayCity() function, output a city greeting to the output div tag in the HTML file. The greeting must contain the city name, with some text added before and after the city name. For example, assuming the user keyed in “Cheddarville” the greeting might be something like, “Hello, Cheddarville. How’s the weather out there?”
  8. Run the final test of the application.
  9. Modify the comment box above the new function. Remember that the original content there was only first draft. Now, with very fresh knowledge of what the function does, revise this comment for completeness, accuracy, and good sentence structure.
