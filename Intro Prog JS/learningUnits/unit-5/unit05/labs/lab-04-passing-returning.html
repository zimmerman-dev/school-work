Problem Statement

Design a program that will prompt a user for their first name, middle initial, and last name. Once the program has these three strings, then have it display the user’s name on the page with this format: “Hello, John T. Public. How are you?”

Lab Steps

  1. Do not use any global variables for this lab.
  2. Add an <h3> element to the HTML page with an id to use as your output.
  3. The main function should prompt user the user for the three parts of their name. It must then call a sub-function to format the name and return it to the main function. The main function must then display (in the <h3> element) the full name with some additional greeting text around it.
  4. Name the sub-function something like: formatFullName() or formatUserFullName(). The function must have 3 parameters: one for the first name, one for the middle initial, and one for the last name. The function should return a string that is the full name with this format, including period for the middle initial. For example, Bob T. Smith

Sample Output

Hello, John T. Public. How are you?
