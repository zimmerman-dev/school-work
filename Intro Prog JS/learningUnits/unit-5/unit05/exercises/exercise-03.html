Part 1

Exercise Steps

  1. Write a program that gets To-Do items from a user, creates an unordered list with the entries, and outputs the list to the page.
  2. Create a global variable that will hold the output element in the HTML file.
  3. Function: exercise3Part1():
    • This function will have a local variable to hold the user input. A loop should ask the user to enter a To-Do item or enter “quit” to stop the loop. Within the loop, a sub-function will be called to add and display the to-do item to an unordered list. The user entry must be an argument in sub-function call. Once the loop is complete, the closing <ul> HTML element will be appended to the HTML output, using the global variable.
  4. Create a new sub-function
    • This function, will have a parameter to receive the user entry. Create a local variable to hold the unordered list, build the unordered list containing the user entry as a list item and output it to the HTML page using the global variable.
