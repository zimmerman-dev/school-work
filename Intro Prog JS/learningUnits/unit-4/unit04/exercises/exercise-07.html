Part 1

Problem Statement

Write a program that asks a user to enter a number. Add the entered number to the total, display the entered number and the total. Keep asking the user to enter numbers. Add each entered number to the total, display the entered number and the total until the total is greater than 1000. Then output the total on a separate line.

Test Plan (Part 1)

Test Case 1

Expected Input: 1001

Expected Output:
Entered Number: 1001,
Current Total: 1001
The final total is: 1001

Test Case 2

Expected Input: 150, 250, 350, 450

Expected Output:
Entered Number: 150, Current Total: 150
Entered Number: 250, Current Total: 400
Entered Number: 350, Current Total: 750
Entered Number: 450, Current Total: 1200
The final total is: 1200

Test Case 3

Expected Input: 1000, 1000

Expected Output:
Entered Number: 1000, Current Total: 1000
Entered Number: 1000, Current Total: 2000
The final total is: 2000

Sample Output (Part 1)

Entered Number: 123, Current Total: 123
Entered Number: 234, Current Total: 357
Entered Number: 345, Current Total: 702
Entered Number: 456, Current Total: 1158

The final total is: 1158

Your Output (Part 1)

Part 2

Problem Statement

Write a program that asks a user to enter even numbers. As long as they enter an even number, display the number with a phrase that says, “ is an even number”. When the user enters a odd number, output the number with the phrase, “ isn’t an even number” and end the program.

Test Plan (Part 2)

Test Case 1

Expected Input: 0, 1

Expected Output:
0 is an even number
1 isn't an even number

Test Case 2

Expected Input: 2, 4, 6, 7

Expected Output:
2 is an even number
4 is an even number
6 is an even number
7 isn't an even number

Test Case 3

Expected Input: 1

Expected Output:
1 isn't an even number

Sample Output (Part 2)

2 is an even number
4 is an even number
5 isn't an even number

Your Output (Part 2)
