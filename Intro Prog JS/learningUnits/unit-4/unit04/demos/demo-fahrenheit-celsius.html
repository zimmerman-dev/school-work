Fahrenheit-Celsius Conversion Program

Problem Statement

A program is to be written that will accept five Fahrenheit temperatures, convert each one to Celsius, and display the converted temperatures on the page. After all 5 have been processed, the program will display the words, “All temperatures processed.” on the page.

Planning List

Input Variables

  • currentFahrenheitTemperature

Output Variables

  • currentFahrenheitTemperature
  • currentCelsiusTemperature
  • finalMessage

Process Checklist

  1. prompt user for 5 temperatures in a loop
  2. convert the inputs to numbers
  3. display each input temperature
  4. display each converted temperature
  5. display finalMessage
