Lab Steps

  1. Global Variable
    • At the very top of the JavaScript file, place a comment line that says “Global variables.”
    • After this comment line, but above the controller function set up a new global variable to hold your full name.
  2. Sub-Function
    • Next create a new sub-function above the main function and below the global variable.
    • Name the sub-function  displayNameOnWebPage().
    • Output the global variable in the sub-function with a document.write() followed by a <br/> element.
    • Add a comment above the sub-function describing it’s purpose.
  3. Controller Function
    • Assign the value of the global variable your name.
    • Call the displayNameOnWebPage() function.
    • When the above steps are working, then call the  displayNameOnWebPage() function a few more times with each call on its own line.

    4. Notice that both the sub-function and the controller function have access to the global variable
