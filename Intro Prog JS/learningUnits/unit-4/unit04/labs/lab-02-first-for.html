Problem Statement

Create a JavaScript program that will ask a user to enter five instances of anything they wish to key in, with each such string of characters displayed on the web page.

Lab Steps

  1. Variable declarations section
    • Write a comment that identifies this coding section.
    • Declare a constant with a name something like LOOP_MAXIMUM, and assign it a value of 5.
    • Declare a constant named INITIAL_LOOP_VALUE and assign 0 to it.
    • Declare a loopCounter variable.
    • Declare a variable to hold a string entered by the user.
  2. Loop Section
    • Write a comment that identifies this coding section.
    • For this lab, we will use a for loop and the loop counter variable.
    • In the for loop header, assign the INITIAL_LOOP_VALUE to the loop counter variable.
    • In the for loop header, for the boolean expression, test if the loop counter variable is less than the LOOP_MAXIMUM.
    • In the for loop header, for the increment section, add one to the counter variable using ++ or += 1.
    • In the loop you should:
      • Prompt the user for an entry and assign it to the string variable.
      • Display what the user entered on the page.
