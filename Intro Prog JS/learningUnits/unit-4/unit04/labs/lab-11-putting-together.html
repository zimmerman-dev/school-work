Part 1

Problem Statement

Write a program that asks a user to enter five numbers. Each number that is entered that is greater than zero should be displayed on the page and added to a total variable. Numbers that are zero or less than zero should be displayed, but not added to the total. After the loop has ended, display the total. See sample output for the required formatting of the output.

Write this program using functions to divide the program up into methods. The controller function should consist of mostly function calls, a WHILE loop, and the IF that does the selection of numbers eligible to be included in the grand total. Continue to use a pool of global variables (and one global constant) in writing this application.

A suggested main function for Part 1 has already been written for you in the JavaScript library file. All of the other functions remain to be written, and the variables all need to be defined as well.
