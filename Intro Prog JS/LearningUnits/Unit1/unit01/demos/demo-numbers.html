Numbers

Take a look at the JavaScript file, demo-numbers.js. The output produced by the code is in the Sample Output box below.

Sample Output

Explanation:

  • Lines 5-6 declare variables that will contain numbers.
  • Line 7 declares a variable that will contain a string.
  • Lines 9 and 10 assign numbers to the variables.
  • Line 11 assigns a string to the variable, even though the contents look like a number. The double-quotes make it a string.
  • Lines 14 writes the count variable to the page. The write function automatically converts the number to a string for display on the web page.
  • Line 18 writes the price variable to the page.
  • Lines 22 adds price and count together and writes the results to the page. This does work technically, but it is ot a good idea to do any math within the parentheses of a write method.
  • Lines 26 writes the priceString variable to the page. Since it is already a string the write function doesn’t need to convert it.
  • Lines 30 “adds” the priceString variable to the count variable and writes the results to the page. However, the plus sign (+) in this case converts the number to a string and then combines both strings together. This is called concatenation.
