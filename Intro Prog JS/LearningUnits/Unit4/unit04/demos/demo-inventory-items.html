Inventory Items Program

Problem Statement

Write a program to read a series of inventory records that contain an item number, and item description and a stock amount. The is to produce a low stock items report, by print only those records that have a stock amount of less than 20 items. A heading is to be printed at the top of the report and a total low stock item count printed at the end.

Planning List

Input Variables

  • inventoryRecords
  • - itemNumber
  • - itemDescription
  • - stockAmount

Output Variables

  • itemNumber
  • itemDescription
  • stockAmount
  • totalLowStockItems

Process Checklist

  1. Declare constants and variables
  2. Read inventory records
  3. Select/find low inventory item records
  4. Print low inventory items records
  5. Print total of low inventory items

Expected Output:
