Student Enrollment Program

Problem Statement

Write a program that will read a file of student records, and select and print only the records of those students enrolled in a course named Programming I.

Each student record contains student number, name, address, zip code, status, and course number.

The course number for Programming I, is 18500.

Three totals are to be printed at the end of the report: total full time enrolled in the course, total part time enrolled in the course, and total students enrolled in the course.

  5. Compute total part time enrolled
