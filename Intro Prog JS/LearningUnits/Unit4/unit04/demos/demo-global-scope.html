Sample Output

What Happened?

Lines 8 and 9: These variables have Global Scope, they’re available to every function in the file. Functions can read and write to them. The ARE NOT indented because they are outside of the function.

let firstName;
let lastName;


Lines 49 and 51: “What? We haven’t see this before!” That’s correct, we are going to start using a different way to add our output to the page. We will use a common technique that sits in between the document.write() function and full DOM Manipulation on the scale of good ways to dynamically change an HTML page. Don’t worry, we’ll go over this a lot. For now just realize that we can get access to the HTML elements on a page with JavaScript.

// Get the list on the page
let list;

list = document.getElementById('demoList');


Lines 54 and 55: This will set the values of the global variables.

// Set the global variables
firstName = "Fred";
lastName = "Flintstone";


Line 59: Adds an <li> tag to the <ul> tag that is already on the HTML page.

// Output the name to the page by
// adding a list element to the <ul> tag
list.innerHTML = "<li>" + firstName + " " + lastName + "</li>";


Line 62: This is the function call to the sub-function in the file. The current function will be suspended and the program will continue running at the beginning of the called function.

// Now call another function
addBarneyElement();


Lines 19 and 21: This function also access to the list element on the HTML page.

    // This function will also get the <ul> tag
// from the document.
let list;

list = document.getElementById('demoList');


Lines 24 and 25: This code is changing the value of the global variables. It overwrites the values set by the first function.

// Set the global variables
firstName = "Barney";
lastName = "Rubble";


Line 29: Here we are adding another <li> element to the <ul> tag. Notice the +=, we need this to not overwrite the other elements that have been added to the <ul> tag.

// Output the name to the page by
// adding a list element to the <ul> tag
list.innerHTML += "<li>" + firstName + " " + lastName + "</li>";


Line 62: Here we are, back at the spot where we suspended the first function. The function will start running again from the next statement after the function call.


Line 66: One final <li> tag will be add to the <ul> tag to see what is currently in the global variables.

// Now add another item to the list to see
// that firstName and lastName now hold.
list.innerHTML += "<li>" + firstName + " " + lastName + "</li>";
