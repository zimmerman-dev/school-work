Part 2

Lab Steps

  1. New Sub-Function
    • Create a new function above the main function lab09Part02().
    • Give the new function a good name that indicates that the function will be outputting a full name. Remember that course standards demand that a function name must begin with a verb, other than for main functions.
    • Add a good comment above the function describing what the function does.
    • Create three variables within the new function.
      • One for a first name
      • One for a middle initial
      • One for a last name.
    • Prompt the user for first name, the middle initial, and the last name, one at a time, of course.
    • Output the user’s full name to the page with a document.write(). Don’t add a <br /> tag to the beginning or the end of the name. Add a period (.) to the end of the middle initial.
  2. Control function: lab09Part02()
    • Output the first half of a greeting. You could do something like, “Hello, “.
    • Then call the sub-function that you wrote. Remember to add the (); at the end of the name of the function.
    • Output the end of a greeting. Something like, ”. How are you?” and a <br /> tag.
    • Call the function that you wrote again. This time don’t output a greeting before you call it.
    • Then, output a relevant statement, most anything you want (see example output below).

Sample Output (Part 2)

Hello, John T. Smith. How are you?
Susan G. Hatch, has left the building.
