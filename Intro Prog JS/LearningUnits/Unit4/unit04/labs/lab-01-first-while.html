Problem Statement

Create a JavaScript program that will ask a user to enter five instances of anything they wish to key in, with each such string of characters displayed on the web page. See sample output below.

Lab Steps

  1. Declaration Section
    • Write a comment that identifies this coding section.
    • Declare a constant with a name something like LOOP_MAXIMUM, and assign it a value of 5.
    • Declare a constant named INITIAL_LOOP_VALUE and assign 0 to it.
    • Declare a variable to be used to control the looping. A name such as loopCounter would make sense.
    • Declare a variable to hold the string entered by the user. A name such as userEnteredString for example would be a good name.
  2. Assignments section
    • Write a comment that identifies this coding section.
    • Assign the loopCounter variable the INITIAL_LOOP_VALUE constant.
  3. Processing Section
    • Write a comment that identifies this coding section.
    • Use a while loop and the loop counter variable.
    • In the while boolean expression, test if the loop counter variable is less than the LOOP_MAXIMUM.
    • In the loop you should:
      • Prompt the user for an entry and assign it to the variable set up above to hold the string entered by the user.
      • Display what the user entered on the page.
      • Increment the loop counter variable.
