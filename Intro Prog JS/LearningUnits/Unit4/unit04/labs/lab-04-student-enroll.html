Problem Statement

Create a JavaScript program that displays student enrollment data on the web page.

Lab Steps

  1. Refer to Student Enrollment Record Set in the lecture notes to view the details about accessing the Student Enrollment Records Set.
  2. As shown in the example, use the function openStudentEnrollmentRecords() to open this record set.
  3. For the JavaScript program you are writing, display just the student number and the student name. As shown in the example program from the lecture notes, you will need to use these functions:
    • getStudentNumber()
    • getStudentName()
  4. Use the readNextRecord() function as the loop conditional.
  5. Study the looping code in lab 3 as another example of looping to read records from files in this course.
  6. Display the all the student numbers and names of the enrollment data.
