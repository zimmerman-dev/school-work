Problem Statement

Write a program that asks a user to enter a number between 1 and 100 that does not include the end points. When a number in the correct range is entered then output the number and a message indicating success. If the number is not in the range then output the number and ask the user to try again.

Lab Steps

  1. Constant declarations section
    • Write a comment that identifies this coding section.
    • Declare a constant for the low endpoint of the range. Assign 1 to the constant.
    • Declare a constant for the high endpoint of the range. Assign 100 to the constant.
  2. Variable declarations section
    • Write a comment that identifies this coding section.
    • Declare a variable that will be used to hold a number.
    • Declare a variable to hold your output message
  3. Assignments section
    • Write a comment that identifies this coding section.
    • Ask the user to enter a number between 1 and 100 that does not include the end points of the range and store it in the number variable.
  4. Validation
    • Write a comment that identifies this coding section.
    • If the input is not numeric, output an error message and stop the function with a return statement.
    • If the input is numeric, convert the input to a number.
  5. Logic section
    • Write a comment that identifies this coding section.
    • If the entered number is in the specified range then build a success statement.
    • If the number is out of the specified range then build the an message.
    • Remember to only use only variables in your logic.
  6. Output section
    • Write a comment that identifies this coding section.
    • Output your message.
