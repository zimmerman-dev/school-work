Problem Statement

Write a program that asks a user to enter a number. If the number is less than 100 then output the number and the message, “ is too little!” If the number is greater than 100 then output the number and the message, “ is too big!” If the number is 100 then output the number and the message, “ is just right!

Tip

After accomplishing Steps 1 and 2 below, you might want to accomplish Step 5, before accomplishing Steps 4 and 5. That way, as the IF statements are added into the program you can see the output. This a great way to test your code as you work!

Lab Steps

  1. Variable declarations section
    • Write a comment that identifies this coding section.
    • Declare a variable to hold a number.
    • Declare a variable to hold the output message.
  2. Assignments section
    • Write a comment that identifies this coding section.
    • Ask a user to enter a number and store it in the variable declared above.
  3. Validation
    • Write a comment that identifies this coding section.
    • Using the isNumeric function, check if the input is not a number.
    • If the input is not a number, make the output message an error message.
  4. Calculations and Logic section
    • Write a comment that identifies this coding section.
    • Convert the entered value to a number using the Number() function.
    • Write 3 separate if statements:
      1. If the number is bigger than 100 then assign the number and “ is too big!” to the message variable.
      2. If the number is less than 100 then assign the number and “ is too little!” to the message variable.
      3. If the number is equal to 100 then assign the number and “ is just right!” to the message variable.
  5. Output section
    • Write a comment that identifies this coding section.
    • Output the message variable to the page.
