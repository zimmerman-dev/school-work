Problem Statement

Write a program that asks a user to enter a string. Then ask the user to enter a string that will sort after the first string in an ASCII sort. (“A” sorts before “B”).

  • If the second string is after the first in an ASCII sort then output a message that includes both strings and a success message.
  • If the second string does not sort after the first string then output the strings and ask the user to try again.
  • Use an IF/ELSE statement, and not just two separate IF statements.
  • A good approach is to have the entire output message stored in a variable, which is displayed as the last step of the program.

Lab Steps

  1. Variable declarations section
    • Write a comment that identifies this coding section.
    • Declare a variable to hold the first string.
    • Declare a variable to hold the second string.
    • Declare a variable to hold the output message.
  2. Assignments section
    • Write a comment that identifies this coding section.
    • Prompt a user to enter a string and store it in the first variable.
    • Prompt a user to enter a string that will sort after than the first one and store it in the second variable.
  3. Validation section
    • Write a comment that identifies this coding section.
    • If the user entered nothing in the prompts, alert an error message telling them to ignore any output and to try again.
  4. Logic section
    • Write a comment that identifies this coding section.
    • If the second string sorts after the first then set the output message to:
      • “Very good, <second string> comes after <first string>.
    • If the second string does not sort after the first then set the output message to:
      • <second string> is the same or does not sort after <first string>, please try again.”
  5. Output Section
    • Write a comment that identifies this coding section.
    • Display the output message variable on the web page
