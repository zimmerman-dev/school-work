Problem Statement

Write a program that asks a user to enter a number greater than 10. If the number is not greater than 10 then write a comment to the page that says they did not enter a number greater than 10. In either case output the number to the page.

Validate that the user has entered a numeric value before doing any logic. If the user enters something that is not numeric alert an error message telling them to ignore any output and to try again.

In this case, the three planning lists based on the verbs and nouns you see in the problem statement have already been done. Remember that not all variables will be on these lists–only variables involved with inputs and outputs from the program are on them. For example, a variable (that is actually a constant) such as LOWER_BOUNDARY would not appear on these lists.

Planning List

Input Variables

Output Variables

  • enteredNumber

Process Checklist

  1. Define all constants and variables
  2. Ask user for a number greater than ten
  3. Display error msg if number is not greater than ten
  4. Display the number
