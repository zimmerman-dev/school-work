Driver's License Example Program

Problem Statement

Write a program that determines if someone gets a driver’s license. The user is prompted for the age of the applicant, if the applicant passed the written exam, and if they passed the behind-the-wheel exam. The applicant is given a driver’s license if they are at least 16 and they passed both exams.

Note: The return statement stops the function. We will cover this in more depth in a later unit.

Planning List

Input Variables

  • age
  • writtenExamResults
  • behindTheWheelExamResults

Output Variables

  • none

Process Checklist

  1. Prompt for age
  2. Prompt for written exam results
  3. Prompt for behind-the-wheel results
  4. Check entered data
  5. Award driver's license or condolences

Test Plan

Test Case 1

Expected Input: Inputs: 16, Y, Y (Note: As written, user must key an uppercase Y)

Expected Output: A Driver's License

Test Case 2

Expected Input: 15, Y, Y

Expected Output: A Condolence

Test Case 3

Expected Input: 16, Y, N

Expected Output: A Condolence
