Divide Safely Program

Problem Statement

Write a program that asks a user to enter two numbers. If the second number is not zero then divide the first number by the second number and output the results to the page. If the second is zero then alert the user that they entered a zero and should try again. Do not output anything to the page if the second number is zero.

Planning List

Input Variables

  • numberOne
  • numberTwo

Output Variables

  • numberOne
  • numberTwo

Process Checklist

  1. prompt user for numberOne
  2. prompt user for numberTwo
  3. check numberTwo for zero
  4. alert user based on value
  5. divide numberOne by numberTwo
  6. output results

Test Plan

Test Case 1

Expected Input: 10, 5

Expected Output: 10 divided by 5 is 2

Test Case 2

Expected Input: 10, 0

Expected Output: You have entered a zero. Please try again.

Test Case 3

Expected Input: 1, 2

Expected Output: 1 divided by 2 is 0.5
