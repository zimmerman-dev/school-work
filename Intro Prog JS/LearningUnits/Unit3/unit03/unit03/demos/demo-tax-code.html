Tax Code Program

Problem Statement

Write a program that will get a customer’s name from the user, a purchase amount, and a tax code. The tax code has been validated and will be one of the following:

CodeTax Amount
0Tax Exempt (0%)
1State Sales Tax (5%)
2State and County Sales Tax (5.5%)
3Special Sales Tax (7%)

The program must then compute the sales tax and the total amount due, and display to the web page the customer’s name, purchase amount, sales tax, and total amount due.

Planning List

Input Variables

  • customerName
  • purchaseAmount
  • taxCode

Output Variables

  • customerName
  • purchaseAmount
  • salesTax
  • totalAmount

Process Checklist

  1. Declare all variables
  2. Obtain customer name, amount, and tax code
  3. Calculate sales tax
  4. Calculate total amount
  5. Display customer details
