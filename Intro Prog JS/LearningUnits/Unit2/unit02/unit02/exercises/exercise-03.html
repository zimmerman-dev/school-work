Part 1

Exercise Steps

  1. Open this file in your browser and your text editor.
  2. Add your name, section, and email to the HTML.
  3. Locate the exercise03Part1() function in the exercise-03.js file.
  4. Variable declarations section
    • Write a comment that starts the variable declaration section.
    • Create a variable named enteredNumber that will hold a number.
  5. Processing and output section
    • Write a comment that starts this section.
    • Prompt the user to enter a number and assign the entered value to the enteredNumber variable.
    • Convert the entered value to a number and assign the number to the enteredNumber variable.
